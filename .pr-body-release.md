## Why

ADR-005 (go-live failure diagnosability, RC1-RC24 + Amendment 1 R10) has been
complete on `main` since `89544fc` but was never cut into a release. Pulsar
ships to consumers only through npm (`docs/runbooks/cut-a-release-and-propagate.md`):
merging to `main` does not put the durable log handler, the structured
failure events, or the diagnostic surface in front of Prism. `ZabLaboratory/Prism#688`
(§3.7 — Prism drops `classifyStartFailure` log-scraping in favour of the new
events) is explicitly gated on this bundle being published and consumed.

## What

`chore(release): v1.8.0` — version bump only, no source change beyond what
already merged to `main`.

- **Minor**, per `docs/DEVELOPMENT.md` § Versioning: the delta since v1.7.0
  is dominated by additive `pulsar:*` surface (`OutputFailed.reason_class`,
  `OutputAttemptSettled`, diagnostic extraction / write circuit-breaker
  requests) and new capabilities, not just fixes.
- `CHANGELOG.md`: full `[1.8.0]` entry reconciled against `git log v1.7.0..origin/main`
  (not the stale `[Unreleased]` section, which only tracked #166/#173) —
  see the diff for the ADR-005 Added/Fixed/Security breakdown, including the
  R10 accepted residual risk (deployment precondition: Pulsar must run
  per-user embedded, true for Prism's shape; a shared install path needs a
  Bastion clearance against R10 before merge).
- `VERSION`, 3 × `package.json` (`pulsar-client`, `pulsar-bundle`,
  `pulsar-bundle-full`), `package-lock.json` refreshed with
  `--package-lock-only --ignore-scripts` (no `postinstall`, no local
  `binaries/` wipe).

## Proof

- Diff shape matches the runbook's expectation exactly: CHANGELOG, VERSION,
  3×package.json, package-lock.json — nothing else (`git status --short`).
- CI (`pipeline.yml`) green on this PR: lint / build / binary-gate /
  offline-probes.
- Release-grade proof (npm publish, zip packaging, live broadcast, Release
  assets) happens on the `v1.8.0` tag after merge, per the runbook — tracked
  in this PR's follow-up comment once the tag run completes.
