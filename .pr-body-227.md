## Cause racine

`ctest --test-dir build --output-junit ctest-junit.xml` (pipeline.yml:463) écrit le
fichier relatif à `--test-dir`, donc `build/ctest-junit.xml`. Le step
`actions/upload-artifact@v4` (pipeline.yml:477-484) déclarait le chemin `ctest-junit.xml`
(racine repo), qui n'a jamais existé. `if-no-files-found: warn` masquait le trou
silencieusement depuis #218 : seul `build/Testing/Temporary/LastTest.log` était
réellement archivé, l'artefact JUnit structuré promis par #218 n'a jamais été
matérialisé en pratique.

## Fix

`path:` du step d'upload aligné sur le chemin réel : `build/ctest-junit.xml`.

## Preuve

Diff d'une ligne, `.github/workflows/pipeline.yml:481`. Vérification définitive à faire
sur le run CI de cette PR une fois déclenché (le job offline probe suite CTest doit
produire un artefact `pulsar-ctest-output` contenant `ctest-junit.xml` non vide).

Refs #227
