## Outcome

The external capture box preserves every finite positive width and height in scene units, including subpixel values. Its render target allocates `ceil(size + 2 * padding)` texels and carries the exact extent-to-raster ratio into the scene transform and shader coordinates. This keeps raster allocation integral while preserving the authored geometry and sampling the edge pixels. Missing/non-finite outer dimensions and explicit nonpositive dimensions retain the historical one-unit fallback.

`CommitAppearance` now passes a private settings snapshot to a new filter and clears/replaces the stored settings on an existing filter before applying a complete appearance. This matters because the qualified libobs source stores `obs_context_data.settings` as `obs_data_newref(settings)` (`obs.c:2752`), while `obs_source_update` overlays entries with `obs_data_apply(source->context.settings, settings)` (`obs-source.c:1109`). Overlaying an incomplete next request leaves keys that were present in the previous request. `obs_source_reset_settings` clears that stored dictionary and then updates it (`obs-source.c:1125-1126`). The filter receives a cloned snapshot, keeping the request object separate from the mutable settings object retained by libobs.

Tolerances are recorded in the probe report. The test also follows a positive subpixel commit with omitted width/height and with explicit `0/-2`; both historical fallbacks assert a `[1, 1]` raster and unit scale.
