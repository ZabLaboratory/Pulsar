## What changed

1. Bounded MSVC file-level parallelism (`/MP2`) in Pulsar's CMake project.
   Baseline had only MSBuild project-level parallelism. The generated
   `pulsar-websocket.vcxproj` confirms `MultiProcessorCompilation=true` and
   `ProcessorNumber=2`.
2. A PCH for `nlohmann/json.hpp` in pulsar-websocket, confirmed as `Use` in the
   generated project. No optimization/debug-symbol or test requirement relaxed.
3. Do not compile upstream obs-browser merely to delete its binaries. The
   Pulsar-owned browser now copies the same CEF runtime payload directly.
4. Consume the Release/Debug wrappers already present in the pinned OBS CEF
   distribution, like upstream OBS does. `/MT`/`/MTd` mapping is retained.
   Source fallback remains, with `PULSAR_REBUILD_CEF_WRAPPER` available for
   intentional CEF development.
5. Exact output cache with conservative source/toolchain/workspace invalidation,
   complete SHA-256 file inventory, producer run/SHA, and no cached test results
   or interpreted probe scripts.
