# Pulsar DirectShow registration validation

## Result

The Pulsar OBS installer now repairs all three per-user DirectShow filters on
every install instead of accepting one pre-existing CLSID as proof that the
registration set is healthy. Both 64-bit and 32-bit registration paths verify
that their expected `InprocServer32` values point to the shipped module.

## Validation

- Focused parent contract suite: 41 passed.
- The CI contract job now checks out recursive submodules before reading the
  OBS installer contract; this closes the Linux runner `FileNotFoundError`
  observed on the first PR run.
- The upstream commit is signed and pushed on
  `eleven/local-20260908-virtualcam-registration`.
- The parent contract asserts that the installer does not skip repair when one
  filter exists, invokes both `regsvr32` architectures, includes every Pulsar
  CLSID, and verifies both registration views.

## Residual boundary

This change repairs installer state. Prism separately performs and verifies the
registration before renderer startup so Chromium does not retain a stale
DirectShow device snapshot.
