La correction AFX crée des handles actualisés sur un worker persistant pour
méthode/intensité/VAD. L'audio conserve le PCM original pendant le chargement ;
le callback ne bloque pas sur ce chargement. Le retrait rejoint le worker avant
de libérer ses données, hors de son mutex. Le logger global vit jusqu'au
déchargement du SDK. Patch 0062, source signée
`6fc5905315af589cde8dc1f7c85212d5ee6ad65a`.

La sonde finale `20261010T111700Z-native-video.json` passe : trois VFX,
bypass exact, 20 switches natifs, trois méthodes AFX aux intensités
0/25/75/100 %, 72 changements rapides, six retraits pendant chargement,
deux filtres audio et continuité du VAD. Aucun diagnostic SDK, arrêt code 0
non forcé. `20261010T111700Z-media-check.json` décode réellement H.264/AAC
et confirme les pixels traités et la variation du signal audio enregistré.

Candidate et DLL intégrée au dev commun : SHA256
`e52040f52b9510ec34afd3e142df276b0252745f8713b655b8943d27f40b1365`.

sont préservés. Replay des patches NVIDIA sur le pin, build MSVC x64 du
