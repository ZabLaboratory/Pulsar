# Installed NVIDIA effects regression

The official Ampere AFX 1.6.1.2 and VFX 0.7.6.0 runtimes were installed as
external Program Files dependencies. This repository does not redistribute
their DLLs/models. Prism integration and installer provenance belong to
`Prism/evidence/local-20261010-nvidia-sdk-integration/eleven/20261010T100100Z-report.md`.

The opt-in `scripts/probe-nvidia-effects.py` reuses existing isolated process,
authenticated WebSocket and graceful shutdown helpers. Native capability and
registration assertions, pixels, exact bypass, five-second frame/performance
windows and three audio processing methods passed against the existing isolated
audit runtime. Binary hashes identify the exact artifact; this probe does not
claim that an unbuilt source revision is the tested artifact.

[Native evidence](20261010T100000Z-native.json) records all four registrations,
three measurable VFX changes, 302–303 rendered frames/measurement with zero
skips, mean render times 2.05–5.54 ms, denoiser noise reduction from magnitude
0.07980 to 0.00490, and normal process exit 0 without forced termination.
The combined audio method reached 0.00723; dereverb also produced processed
audio but its acoustic echo-removal quality is not established by white noise.

SDK diagnostics are retained, including `Missing src dst` during video setup
and null logger callbacks during lifecycle. They are unresolved and explicitly
separate from the functional/performance pass. This is not evidence of zero
runtime errors, human portrait quality or real-room acoustics. The fixtures use
no physical capture, recording, network broadcast or speaker monitoring.

The shared Prism integration owner independently verified the registered kinds,
creation/settings readback/removal, Preview and ProgramReturn; its proof remains
in `Prism/.worktrees/eleven-local-20261008-scene-sync/evidence/local-20261010-nvidia-sdk-integration/eleven/20261010T095635Z-checkpoint.json`.

Packaging source checks pass and prohibit SDK/model payloads in product bundles.
Python syntax and whitespace checks pass. The probe and its nearest-owner README
are the only product/test changes here; native effect plugin code is unchanged.
