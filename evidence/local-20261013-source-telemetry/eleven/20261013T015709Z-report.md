## Cause démontrée

Le module websocket actif annonçait GetSourceStats mais renvoyait 207 `SOURCE_TELEMETRY_REQUIRES_UPDATED_LIBOBS`. La DLL réellement chargée par Pulsar était `C:/Users/Mathias/AppData/Roaming/prism-dev/components/pulsar/active/bin/64bit/obs.dll`, SHA256 `fc8eb80e1104b39501e5c23113c5b2e73138334cd4c1c0f98f9e158f9cf46048`.

Ses exports incluaient le getter RAM, enable/fill-result/gpu-enable du profiler ; `source_profiler_request_telemetry` était absent. Le handler Windows refuse précisément l'absence de cette fonction par GetProcAddress. Il n'utilise pas un profiling permanent en remplacement. Le problème était donc un mélange de core et de module, pas un endpoint GetVersion inexistant.
